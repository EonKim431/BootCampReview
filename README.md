# BootCampReview

풀스택 부트캠프에서 개발한 CRM 프로젝트를 다시 분석하고 개선하는 프로젝트입니다.

기존 코드를 재검토하며 프로젝트 구조와 데이터 흐름을 분석하고, 개선 과정을 기록합니다.

## Goals

* 프로젝트 구조 분석
* 코드 리팩토링
* 예외 처리 개선
* 검색 기능 고도화
* 페이징 기능 추가
* 프로젝트 문서화

## Phase 1. Project Analysis

* 프로젝트 실행
* Controller 분석
* Service 분석
* Mapper 분석
* DB 구조 파악
* 기능별 데이터 흐름 정리
